# ffmpeg

Put `ffmpeg.exe` here; the default is `-ffmpeg ./ffmpeg/ffmpeg.exe`. If it's missing, `ffmpeg` on the PATH is used.

Use a "full" build: the presets need libx264, libx265, prores_ks and dnxhd, and the burn-ins need the drawtext filter (libfreetype). Windows builds are available from https://www.gyan.dev/ffmpeg/builds/ or https://github.com/BtbN/FFmpeg-Builds.

The contents of this folder are not in git.
